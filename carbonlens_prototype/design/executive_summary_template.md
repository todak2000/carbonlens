### Verdict Block (large, coloured)

```
┌─────────────────────────────────────────────┐
│                                             │
│   ✓  VIABLE FOR CO₂ STORAGE                │
│      Recommended for detailed feasibility   │
│                                             │
└─────────────────────────────────────────────┘
```

Colour coding:
- Green = VIABLE
- Amber = NEEDS FURTHER STUDY
- Red = NOT RECOMMENDED

Verdict logic (already in simulation engine):
- VIABLE: containmentProbability > 0.75 AND safetyFactor > 1.5
- NEEDS FURTHER STUDY: containmentProbability 0.5–0.75 OR safetyFactor 1.0–1.5
- NOT RECOMMENDED: containmentProbability < 0.5 OR safetyFactor < 1.0

## Implementation Notes

- Use existing jsPDF infrastructure
- Verdict logic pulls from `SimulationResult.containmentProbability` and `GeomechanicsResult.safetyFactor`
- Bar chart: draw as filled rectangles in jsPDF (no chart library needed)
- Colour scheme: match CarbonLens brand (dark navy, accent green/amber/red)
- One page only — do not paginate
