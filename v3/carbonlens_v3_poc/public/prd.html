Interfacial Tension: Why ML and Not Classical?

IFT is the one CO₂-brine property that cannot be accurately predicted by classical thermodynamic correlations alone — it requires training on experimental data spanning both subcritical and supercritical CO₂ regimes.

MARS Model Overview

  • Algorithm: Multivariate Adaptive Regression Splines (Friedman, 1991)
  • Training data: 3,000+ CO₂-brine IFT experimental datapoints (MSc research, UTP Malaysia)
  • Two regimes: Subcritical and Supercritical CO₂
  • Auto phase detection: Kay's mixing rule for effective Tc and Pc

Feature Inputs

FeatureDescription
PrReduced pressure (P / Pc_eff)
TrReduced temperature (T / Tc_eff)
drho_sqDensity difference squared (CO₂ − brine)²
CH₄Methane mole fraction in CO₂ stream
N₂Nitrogen mole fraction in CO₂ stream
MCM / BCMMolality correction multipliers

Feature scaling: [-1, 1] min-max normalization applied before evaluation

MARS Hinge Function

H(x, knot, dir=1)  = max(0, x − knot)   // forward hinge
H(x, knot, dir=-1) = max(0, knot − x)   // reverse hinge
H(x, knot, dir=2)  = x                  // linear term

Phase Regimes

Subcritical CO₂
T < 304.13 K OR P < 7.38 MPa
16-term MARS equation · Intercept: 51.62 mN/m
Supercritical CO₂
T ≥ 304.13 K AND P ≥ 7.38 MPa
35-term MARS equation · Lower intercept regime

Phase Detection (Kay's Rule)

Tc_eff = Σ(yᵢ · Tcᵢ)   // mole-fraction weighted
Pc_eff = Σ(yᵢ · Pcᵢ)   // critical pressure mix

Output: IFT in mN/m — typical range 10–70 mN/m for CO₂-brine systems at reservoir conditions

The Other 6 Properties: Published Correlations

Only IFT needs ML. The remaining 6 properties are implemented from textbook equations — correct implementation of validated, peer-reviewed correlations. No training data required.

Property Model / Correlation Reference Key Formula / Approach
CO₂ Density Span-Wagner EOS Span & Wagner (1996) Iterative Z-factor from reduced T and P; full Helmholtz energy formulation with 42 terms
CO₂ Viscosity Fenghour et al. Fenghour et al. (1998) η(T) + η(ρ) polynomial expansion — dilute gas term plus density-dependent correction
CO₂ Solubility Duan-Sun Model Duan & Sun (2003) ln K = f(T,P) with salting-out λ term; valid 0–100°C, 0–600 bar, 0–4.5 mol/kg NaCl
Brine Density Garcia Correlation Garcia (2001), LBNL ρ_pure + A·S + B·S^1.5 + C·S² where S = salinity (g/kg). Accounts for dissolved CO₂ volume change.
Diffusion Coefficient Literature Ensemble Multiple sources D₀·(T/298.15)·exp(-P_corr)·φ/τ — tortuosity and porosity corrections applied
Phase Detection Kay's Mixing Rule Kay (1936) Tc_eff, Pc_eff weighted by mole fractions — selects MARS regime for IFT evaluation

Validation Approach

  • CO₂ density compared against NIST WebBook reference data ± 0.5%
  • Sleipner Utsira formation: computed properties match published injection data
  • 10 Vitest test cases for density monotonicity across P/T space
  • Duan-Sun solubility verified against experimental literature values

Implementation Notes

  • All calculations execute synchronously in <5ms per property
  • No external API calls — all equations embedded in TypeScript
  • Unit handling: SI inputs (Pa, K, kg/m³) throughout engine
  • Edge cases handled: T→Tc, P→0, pure water (S=0) limits

Simulation Physics: Theis + DOE Storage Framework

Pressure Buildup — Theis Transient Flow

ΔP = (Q·μ) / (4π·k·h) × E₁(r²·φ·μ·cₜ / 4·k·t)

Where:
  Q   = injection rate (m³/s)
  μ   = CO₂ viscosity (Pa·s)
  k   = permeability (m²)
  h   = formation thickness (m)
  r   = radial distance from well (m)
  φ   = porosity (fraction)
  cₜ  = total compressibility (1/Pa)
  E₁  = exponential integral function

Multi-well superposition:
ΔP_total = Σᵢ ΔPᵢ(rᵢ, tᵢ)
Each well's pressure contribution summed at every grid point — captures well interference effects automatically

DOE Storage Capacity Framework

V_CO₂ = A × h × φ × ρ_CO₂ × E

  ρ_CO₂ = in-situ CO₂ density (kg/m³)

Geomechanics: Ensuring Safe Injection Pressures

🔒

MAIP

Maximum Allowable Injection Pressure
MAIP = σᵥ × FPG
     − (α × Pₒ)

σᵥ  = vertical stress (MPa)
FPG = fracture pressure gradient
    (Eaton correlation)
α   = Biot coefficient
Pₒ  = initial pore pressure

Injection pressure must stay below MAIP at all times to prevent hydraulic fracturing of caprock.

⚠️

Mohr-Coulomb

Failure Criterion
τ_failure = c + σₙ × tan(φ)

c  = cohesion (MPa)
σₙ = effective normal stress
φ  = internal friction angle

τ_shear < τ_failure → SAFE
τ_shear ≥ τ_failure → FAIL

Shear stress on critically oriented faults must remain below the failure envelope throughout injection.

📡

Induced Seismicity

Coulomb Failure Function (DCFF)
DCFF = Δτ − μ × (Δσₙ − ΔP)

Δτ  = shear stress change
μ   = friction coefficient
Δσₙ = normal stress change
ΔP  = pore pressure change
LOWDCFF < 0.1 MPa
MODERATE0.1 – 0.5 MPa
HIGHDCFF > 0.5 MPa

Pre-Flight Validation Checks

Six Parametric Reservoir Geometries

⛰️

1. Anticline

Compressional fold structure. Sine-wave deformation of geometry grid. Classic trap for conventional CCS — buoyancy drives CO₂ to structural high.

Most Common CCS Trap
🔵

2. Dome

Radial structural high. Salt dome analogue with radial bulge displacement. 4-way dip closure in all directions — ideal containment geometry.

4-Way Closure
⚡

3. Fault

Vertical offset with smoothstep transition zone. Fault-bounded trap. Models both sealing and transmissive fault scenarios for risk assessment.

Risk Assessment
📏

4. Layered

Horizontal strata modelling deltaic and fluvial sequences. Flat banded structure with inter-layer heterogeneity. Ideal for saline aquifer scenarios.

Saline Aquifer
🌊

5. Stratigraphic

Dipping layers with complex heterogeneity. Represents pinch-out traps and unconformity-bounded storage — common in passive margin settings.

Passive Margin
🌀

6. Channel

Sinuous meandering channel deposit. High permeability corridor within lower-perm floodplain — models preferential flow pathways for CO₂ migration.

Flow Pathway

Drag-and-drop a LAS file → auto-populates formation porosity and permeability from measured well log curves, replacing estimated parameters with real field data.

Bulk DensityRHOBCross-check density calculation

Technical Implementation

  • Parses LAS 2.0 format (CWLS standard)
  • Handles ~CURVE and ~A sections with whitespace-delimited data
  • Linear interpolation for depth resampling to formation interval
  • Updates Zustand formation store with log-derived values
  • Triggers immediate 3D and simulation recalculation
